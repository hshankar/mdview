# Security policy

## Supported versions

Security fixes are made on the latest tagged release and the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/hshankar/mdview/security/advisories/new) to send a report with:

- A description of the issue and its impact
- Reproduction steps or a proof of concept
- The affected mdview version and macOS version

The project aims to acknowledge reports within seven days and will coordinate a fix and disclosure through the advisory.
